Nuclear Isotope Identification Lab v1.0.0
مختبر التعرف على النظائر - المشروع التاسع

للتشغيل السريع:
1. فك ضغط المشروع.
2. افتح مجلد dist.
3. افتح NuclearIsotopeID-Lab.html في متصفح حديث.
هذه نسخة مستقلة، ولا تحتاج تثبيت Node.js لاستخدامها.

للتطوير:
ثبّت Node.js 24، وافتح الطرفية داخل مجلد المشروع ثم نفّذ:
npm ci
npm run dev

المجلد يتضمن الكود الكامل، والبناء الإنتاجي، وقاعدة خطوط جاما،
وملفات المصدر الخام، والاختبارات، والتوثيق العلمي، وتقارير التحقق.
ابدأ مراجعة النتائج من:
docs/FINAL_VALIDATION_REPORT.md
verification/Scientific-Validation-Report.pdf

ملاحظات علمية:
- المثال الافتتاحي محاكاة معلنة، وليس طيفًا تجريبيًا.
- استيراد بيانات جديدة يمسح كفاءة الكاشف المستخدمة في المحاكاة.
- تطابق خط واحد لا يثبت وجود النظير.
- درجة الأدلة وتغطية القمم ليستا احتمالًا لصحة التعرف.
- راجع تقييم كل نظير والتفسيرات البديلة والقمم غير المفسرة.
- لم تُعاير تصنيفات الأدلة على حملة قياسات تجريبية مستقلة.

التحقق:
نجحت اختبارات Vitest المسجلة وفحوص البيانات والبناء.
عدد الاختبارات ونتائجها الفعلية في verification/summary.json.
اختبارات Playwright للكمبيوتر والهاتف مرفقة، لكنها لم تُشغَّل هنا.
اختبار DOM لا يعادل فحص العرض والتنزيل داخل متصفح حقيقي.

GitHub:
ارفع محتويات مجلد NuclearIsotopeID-Lab إلى جذر مستودعك،
بما فيها .github وpackage.json وsrc وdata وdocs.
لا ترفع ملف ZIP وحده على أنه موقع جاهز.
تعليمات النشر في docs/GITHUB.md.
لم يُنشر أي شيء، ومسار النشر يتطلب تشغيلًا يدويًا وموافقة صريحة.
